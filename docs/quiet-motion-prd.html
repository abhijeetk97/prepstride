02 · Goals and non-goals

Make effort feel seen, without adding noise

Goals

  • Every state change on a primary flow (log, tick, start, save, delete) gets a short, readable transition.
  • Pip becomes a vector character with real poses that respond to the timer, the goal and rest days.
  • The home screen reads at a glance: today's hours, the subject mix and the streak, in that order.
  • One motion system (tokens, three tiers) that every screen uses.
  • Visual hierarchy through type, elevation and the subject colours already in SUBJECT_META.

Non-goals

  • No new ranks, badges, cosmetics or XP mechanics. Pip's accessories stay tied to the existing seven ranks.
  • No confetti. The single daily celebration replaces it.
  • No sound by default and no push notifications.
  • No animation that makes an action slower. The 3-second logging rule from PRD.md holds.
  • No desktop redesign. Phone-first at 390px stays the target.

03 · Principles

Four rules every animation must pass

Motion explains state

An animation shows where something came from or went to: a session flying into the timesheet, a ring closing. If it explains nothing, cut it.

Celebrate effort, quietly

One celebration a day, when the target is truly met. Small acknowledgements (a check drawing in, +10 XP drifting up) cover everything else.

Numbers land exactly

Count-ups always finish on the true value, and screen readers only hear the final number. Animation never shows progress that isn't in the data.

Calm by default, kind to batteries

Loops are slow and few, pause when the app is hidden, and stop under reduced motion. The zen timer is the only screen with ambient motion.

04 · Motion system

Tokens, choreography and three tiers

Durations and curves live as CSS custom properties and Tailwind theme keys, so components never hard-code timing. The current pop and slide-up curves carry over as the spring and sheet curves.

TokenValueUsed for
--dur-instant90 msPress feedback (scale .96), colour on tap
--dur-quick160 msChips, checkboxes, toggles, exits
--dur-base240 msScreen fades, toasts, label swaps
--dur-slow420 to 480 msSheets, ring segments, nav pill
--dur-story900 msCount-ups and the full home arrival sequence (cap)
--dur-ambient3.6 s to 46 sPip breathing, zen halo, ambient drift
--ease-standardcubic-bezier(.2,0,0,1)Colour, opacity, small moves
--ease-emphcubic-bezier(.05,.7,.1,1)Elements arriving: rings, rows, panels
--ease-exitcubic-bezier(.3,0,.8,.15)Elements leaving; always faster than the entry
--ease-springcubic-bezier(.34,1.56,.64,1)Pops: checkbox, chip select, shield earned
--ease-sheetcubic-bezier(.32,1.22,.5,1)Bottom sheets and toasts (slight overshoot)

Choreography. Stagger siblings by 50 to 70 ms, never more than five items, and keep any sequence under 900 ms. Exits take about 60% of the entry time. Every animation can be interrupted, and a second tap always wins over a running transition.

TierWhenWhat runs
FullDefaultEverything in this document.
CalmOS reduced motion is on, or chosen in SettingsOpacity, colour and progress fills only. No movement, scaling, loops, feathers or ambient drift. Count-ups still run.
OffChosen in SettingsInstant state changes. Numbers show their final value immediately.

05 · Interactive mockups

Ten moments, built to spec

Each phone below is live. Mockups replay when they scroll into view, and most respond to taps. Switch the motion tier to check how each one degrades. Hours, streaks and dates are example data.

Applies to every mockup on this page. Calm starts selected if your device asks for reduced motion.

M1 · HOME

Home arrival

The ring draws one subject at a time while the total counts up to the exact logged minutes. Stats follow in a short stagger. Pip appears once, in the header, breathing and blinking.

Trigger
First Home render of the day, or returning to Home after 30 minutes away. Plain tab switches skip the sequence.
Sequence
Header fade (0 ms) → ring segments, 550 ms each, starts staggered by subject share → count-up 900 ms, ease-out cubic → legend and stats at 60 ms stagger from 600 ms.
Visual
The ring is split by subject in SUBJECT_META colours. The hero card gets elevation level 2. A time-of-day tint sits behind the header. Emoji stat icons become drawn icons.
Calm / Off
Calm: segments fill in place and numbers count without movement. Off: final state at once.
Done when
The count-up ends on the same value as formatMinutes(todayMinutes). The aria label carries the final value from the first frame. No layout shift during the sequence.

M2 · CELEBRATION

Target met, once a day

Replaces ConfettiBurst. The ring closes, pulses twice, and Pip flaps and hops while a few feathers in Pip's wing colours drift down. The message swaps from "10m to go" to "Target met".

Trigger
The day's total first reaches the target. Fires once per local day, using the existing celebrated_<date> key. Ritual taps never re-trigger it.
Timing
Ring close 750 ms → glow 2 × 1.1 s → Pip flap 8 × 260 ms plus hop → 12 feathers, 2.4 to 3.4 s each. Done by 4 s, and taps work throughout.
Haptics
One 12 ms navigator.vibrate pulse where supported (Android Chrome). iOS Safari has no vibrate API and gets none.
Calm / Off
Calm: ring fill and message swap only, no feathers or flapping. Off: message only.
Done when
ConfettiBurst is deleted. A test proves a second ritual toggle after the goal does not celebrate.

M5 · BOTTOM SHEET

Quick log, with a save you can see

The sheet springs up over a blurred backdrop. The selected subject chip fills with its colour. A highlight slides between duration options instead of jumping. Save turns into a check, the sheet drops away, and the new session grows into the timesheet with a short highlight.

Timing

Gesture
Drag down on the handle to dismiss, with velocity above 0.5 px/ms or distance above 30%. Every modal gets an exit animation; today Modal returns null immediately.

Pause freezes every loop on the screen.

M6 · ZEN TIMER

A screen you can breathe with

A warm halo behind Pip expands for 4 seconds and contracts for 4. A cue fades between "Breathe in" and "Breathe out". An arc traces the Pomodoro. Digits roll instead of flicking, and two blurred colour fields drift slowly across the background. Pip wears spectacles and blinks slowly.

Battery
CSS-only loops on transform and opacity. Everything pauses on visibilitychange, and the arc updates once per second rather than per frame. A Screen Wake Lock is requested while zen is open, with rejection handled.
Break phase
Pip switches to the sleep pose, the halo cools to sky blue, and the cue changes to "Rest your eyes".
Calm / Off
No halo, drift or blinking. The arc and digits still update without rolling.

Settings: add motion: 'system' | 'full' | 'calm' | 'off' to settings, defaulting to 'system', and keep old JSON backups restoring cleanly.

// src/hooks/useMotionPreference.ts
export type MotionLevel = 'full' | 'calm' | 'off';

export function useMotionPreference(setting: MotionLevel | 'system'): MotionLevel {
  const [osReduce, setOsReduce] = useState(
    () => matchMedia('(prefers-reduced-motion: reduce)').matches
  );
  useEffect(() => {
    const mq = matchMedia('(prefers-reduced-motion: reduce)');
    const onChange = () => setOsReduce(mq.matches);
    mq.addEventListener('change', onChange);
    return () => mq.removeEventListener('change', onChange);
  }, []);
  const level = setting === 'system' ? (osReduce ? 'calm' : 'full') : setting;
  useEffect(() => { document.documentElement.dataset.motion = level; }, [level]);
  return level;
}
// App.tsx: screen transitions without a dependency
const navigate = useCallback((r: Route) => {
  const go = () => { window.location.hash = `/${r}`; setRoute(r); window.scrollTo({ top: 0 }); };
  if (!document.startViewTransition || document.documentElement.dataset.motion === 'off') return go();
  document.startViewTransition(() => flushSync(go));
}, []);

11 · Open questions

Decisions needed before p1 starts

  • Who redraws Pip? An illustrator can deliver a layered SVG from the official art, or the rig can be drawn in-house from simple shapes, as on this page. The first looks better, the second ships sooner.
  • Haptics: are short vibration pulses welcome on Android, or should the app stay silent?
  • Breathing cue in zen: on by default, or opt-in for sessions longer than 25 minutes?
  • Theme-specific ambience: should LBSNAA Gold or Zen Forest get their own zen colour fields, or should all themes share one?
  • motion library: adopt it for the sheet gesture, or hand-roll drag with Pointer Events to stay dependency-free?
